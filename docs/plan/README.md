# 每日学习计划（Markdown 版）

本目录把 20 周计划拆到"每天做什么"，与两份产物配合使用：

- 计划正文：`docs/AI Agent工程化学习计划（含仓库规范与首日清单）.docx`（阶段目标、项目设计要求、验收口径的唯一来源）。
- 进度登记：`docs/AI Agent学习进度清单.xlsx`（周清单、每日记录、阶段门槛、能力自检四张表）。
- 执行记录：`docs/experiments/`，一天一份，写完当天就在里面记数字。

本目录只负责"今天做什么、做到什么算完成"，不重复计划正文里的设计说明。

## 节奏

每周 12 小时，按七天摊：1 + 2 + 2 + 1 + 3 + 1 + 1 小时。最后 1 小时是缓冲，只补欠账，不排新任务。集成调试的耗时通常是编码的两倍，把七天排满的计划第三周就会崩。

每天开工先读当天的三行（日期、要做的事、完成标志），收工在实验记录里补两个数字：步数与成本。周日把结果回填进度清单，未达标的项在阶段门槛里写清是补做还是延后。

## 约定

- Day 编号连续到底：第 1 周是 Day 1 至 Day 7，第 N 周是 Day 7N-6 至 Day 7N，不按星期几命名，避免跨年、跨假期时错位。
- 日期以 2026-11-07 为 Day 1 的起点排；实际顺延就整体后移，编号不变。
- 每天只安排一件事为主，做不完就挪到当周缓冲日，不顺延成"明天做两件"。
- 所有验收都要求能用文件、命令或 trace 核对；写不出核对方式的，不算验收。
- 代码与实验记录尽量分两次提交，便于回溯；`.env`、`traces/`、`out/` 不入库。
