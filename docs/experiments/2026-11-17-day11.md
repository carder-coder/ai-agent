### BM25 设计

- 切分单位是"轮"（一条 assistant 响应及其全部 tool 结果），避免把工具调用与结果拆散。
- 分词不引额外依赖：英文/数字按词，中文按相邻二元组；查询取 system+首条 user 锚点里的 user 文本。
- 标准 BM25：`idf = ln(1 + (N - df + 0.5)/(df + 0.5))`，`k1=1.5`、`b=0.75`。
- 锚点与最近 `RETRIEVAL_KEEP_RECENT=1` 轮固定保留；其余轮次按分数降序选，
  累加字符数不超过 `RETRIEVAL_BUDGET_CHARS=3000`；选中后按原顺序拼回。
- 预算连锚点+最近轮都不够时标记 `over_budget`，但仍保留最近轮，保证对话连续。
- 被裁轮次写入 `context.dropped_detail`（索引、工具名、字符数、120 字预览、BM25 分数），
  供 11-19 的 badcase 定位。

### 四个策略的参数集中

`src/agent/context/config.py` 现在是唯一参数入口：

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| `DEFAULT_WINDOW_TURNS` | 2 | window 保留轮数 |
| `SUMMARY_TRIGGER_CHARS` | 3000 | summary 触发阈值 |
| `SUMMARY_KEEP_TURNS` | 2 | summary 保留轮数 |
| `SUMMARY_MAX_TOKENS` / cap | 800 / 2000 | 摘要输出预算与重试上限 |
| `RETRIEVAL_BUDGET_CHARS` | 3000 | 检索策略字符预算 |
| `RETRIEVAL_KEEP_RECENT` | 1 | 检索策略固定保留的最近轮 |
| `BM25_K1` / `BM25_B` | 1.5 / 0.75 | BM25 参数 |

第 2 周四策略齐：`full`、`window`、`summary`、`retrieval`。
