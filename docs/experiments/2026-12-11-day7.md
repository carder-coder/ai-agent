## 成本口径

成本报告由 `GET /cost-report` 提供，统计当前进程启动以来的进程内快照：

- 每千次对话成本 = 累计成本 / 对话数 × 1,000；对话数为 0 时返回 0。
- 分模型成本占比 = 单模型成本 / 总成本；总成本为 0 时没有可比较的模型占比。
- 语义缓存命中率 = 命中数 / 可缓存查询数；没有查询时返回 0。
- 服务重启会重置进程内统计，因此该报告不能代替跨重启的持久化账单。
