当天任务见 [week-04.md](../plan/week-04.md)：配置日预算、单请求上限并以明确错误码拒绝超限请求，同时留痕。

## 结果

- 默认日预算 100 元、单请求成本上限 0.50 元；环境变量可覆盖；未显式给出输出 token 上限时网关补 `max_tokens=4096`。
- 预检按 messages UTF-8 字节数估计输入上界，忽略缓存折扣并按最贵输入价计算；估算值向上取整到万分之一元后原子预留。
- 上游 usage 返回后以真实成本结算；并发请求通过预留避免共同超支。
- Provider 未返回 usage、流式响应中断或用量无效时，按预留估算额保守计费，避免以零成本记账。
- 预算账本持久化到 `traces/budget.json`；状态文件损坏/不可写时请求失败，不静默放行。重启恢复时未结算预留保守地计入已用额度。
- 超单请求上限返回 `429/request_cost_limit_exceeded`，日预算不足返回 `429/daily_budget_exceeded`；拒绝 trace 写入估算和错误码。
